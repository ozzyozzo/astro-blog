# Instrucciones para agentes

## Agent skills

### Issue tracker

Las incidencias y especificaciones de este proyecto se gestionan en GitHub Issues. Consulta `docs/agents/issue-tracker.md`.

### Triage labels

Usa las cinco etiquetas de clasificación del proyecto. Consulta `docs/agents/triage-labels.md`.

### Domain docs

El proyecto usa un solo contexto de dominio. Consulta `docs/agents/domain.md` antes de trabajar con términos o decisiones del dominio.
