# Etiquetas de clasificación

Las skills de ingeniería usan cinco estados. La columna «Etiqueta en GitHub» indica el texto exacto que debe aplicarse en `ozzyozzo/astro-blog`.

| Estado de la skill | Etiqueta en GitHub | Significado |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Necesita evaluación inicial. |
| `needs-info` | `needs-info` | Espera información de quien creó la incidencia. |
| `ready-for-agent` | `ready-for-agent` | Especificación lista para que la tome un agente. |
| `ready-for-human` | `ready-for-human` | Requiere implementación o decisión humana. |
| `wontfix` | `wontfix` | Se decidió no realizar el trabajo. |

Cuando una skill mencione un estado, usa su etiqueta correspondiente. La etiqueta `wontfix` ya existía en el repositorio antes de esta configuración.
