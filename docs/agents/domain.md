# Documentación del dominio

Este repositorio usa un solo contexto de dominio. Las skills de ingeniería deben consultar estos documentos antes de explorar una parte relevante del código:

- `GLOSSARY.md` en la raíz, si existe: usa los términos definidos allí en incidencias, propuestas y pruebas.
- `docs/adr/`, si existe: lee los registros de decisiones que afecten el área de trabajo y señala cualquier conflicto explícitamente.

La ausencia de estos archivos no bloquea el trabajo. El glosario y los registros de decisiones se crean cuando aparecen términos o decisiones que merece la pena conservar, no como requisito inicial.
